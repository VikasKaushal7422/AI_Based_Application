        About this project

        AI Powered LMS is a front-end prototype of a learning platform for computer science students. It brings the course catalogue, a natural-language search, a doubt assistant and progress tracking into one dashboard.

        Everything here runs in the browser with plain HTML, CSS and JavaScript. Search results and assistant replies come from data stored in script.js, so the page works offline with no server, database or model behind it.
